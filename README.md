# Item Pull

Item Pull lets you gather scattered drops with a single right click

Aim at an item lying on the ground and right click - all matching items nearby are pulled to it instantly

![preview](https://i.postimg.cc/pVQzhhLq/2026-09-26-11-18-47.gif)

## Features

- Pull matching dropped items to the one you look at
- Works with right click on blocks or in the air
- Configurable pull radius
- Optional NBT matching to only pull identical items

![preview](https://cdn.modrinth.com/data/cached_images/6e890b3e4da4f9d6917fda733ef41f7c67ca881e.png)

## Configuration

- **Radius** - how far around the aimed item to search for matching drops
- **Match NBT** - pull only identical items or all items of the same type

Requires [Simple Config Lib](https://github.com/BizCub/simple-config-lib)
